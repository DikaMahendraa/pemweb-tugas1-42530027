# Developer Portfolio

Website portfolio pribadi yang dibuat sebagai bagian dari tugas Pemrograman Web. Website ini menampilkan profil singkat, proyek yang pernah dikerjakan, kemampuan teknis, sertifikasi, serta informasi untuk terhubung secara profesional.

## Deskripsi

Website ini dirancang dengan konsep **Professional Software Developer Portfolio** menggunakan HTML5 dan CSS3. Struktur halaman menggunakan elemen semantik HTML agar konten lebih terorganisir, mudah dibaca, dan mendukung aksesibilitas.

Website dibuat dengan pendekatan **mobile-first** dan responsive sehingga dapat digunakan pada berbagai ukuran layar, mulai dari perangkat mobile hingga desktop.

## Fitur

* Profil dan informasi singkat developer
* Daftar proyek yang pernah dikerjakan
* Informasi teknologi dan technical skills
* Sertifikasi dan learning track
* Informasi kontak
* Link GitHub untuk networking
* Responsive layout untuk mobile, tablet, dan desktop
* Navigasi antarbagian halaman
* Tombol Back to Top

## Teknologi yang Digunakan

* **HTML5** — membangun struktur dan konten halaman
* **CSS3** — styling, layout, responsive design, Flexbox, dan CSS Grid
* **Git** — version control
* **GitHub** — repository dan publikasi project

## Struktur Halaman

Website terdiri dari beberapa bagian utama:

1. **Home** — halaman pembuka dan pengenalan singkat
2. **About** — informasi mengenai developer
3. **Projects** — daftar project yang pernah dibuat
4. **Tech Stack** — kemampuan dan teknologi yang digunakan
5. **Credentials** — sertifikasi dan proses pembelajaran
6. **Contact** — informasi untuk menghubungi developer

## Project yang Ditampilkan

### Smart Library System

Aplikasi sistem perpustakaan berbasis Java dan MySQL yang menerapkan konsep Object-Oriented Programming (OOP).

**Tech:** Java, MySQL, OOP

### Real Estate Landing Page

Landing page bertema real estate yang dibuat dengan pendekatan modern dan responsive.

**Tech:** React, Vite, CSS

### Inventory Management

Aplikasi pengelolaan stok barang yang mencakup pengelolaan data dan operasi CRUD.

**Tech:** PHP, MySQL, CRUD

## Responsive Design

Website menggunakan pendekatan **mobile-first** dengan beberapa breakpoint:

* Mobile: ukuran layar kecil
* Tablet: `min-width: 768px`
* Desktop: `min-width: 1024px`

CSS Grid digunakan untuk layout utama dan kartu project, sedangkan Flexbox digunakan untuk pengaturan layout satu dimensi seperti navigasi dan elemen dalam kartu.
